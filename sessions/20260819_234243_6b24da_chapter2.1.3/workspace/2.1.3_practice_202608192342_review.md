## ❌ 错误记录

### 错误1：拼写错误 + 调用对象错误（M3/M4 四分位数计算）
- **错误代码**：`Q1 = pd.quantite(0.25)` / `Q3 = pd.quantite(0.75)`
- **正确写法**：`Q1 = data[numeric_cols].quantile(0.25)` / `Q3 = data[numeric_cols].quantile(0.75)`
- **原因**：① `quantite` 拼写错误，应为 `quantile`；② `quantile()` 是 DataFrame/Series 的方法，不是 `pd` 模块的方法，需要对数据框调用

### 错误2：逻辑错误（M5 IQR计算）
- **错误代码**：`IQR = Q1 - Q3`
- **正确写法**：`IQR = Q3 - Q1`
- **原因**：IQR（四分位距）= 第三四分位数 - 第一四分位数，即 Q3 - Q1，不是 Q1 - Q3

### 错误3：变量错误（M8 重复值检查）
- **错误代码**：`duplicates = data.duplicated()`
- **正确写法**：`duplicates = data_cleaned.duplicated()`
- **原因**：应该对清洗后的数据 `data_cleaned` 检查重复值，而非原始 `data`

### 错误4：变量错误（M11/M12 特征选择）
- **错误代码**：`X = data.drop(columns=['Unnamed: 0', target_variable])`
- **正确写法**：`X = data_cleaned.drop(columns=['Unnamed: 0', target_variable])`
- **原因**：应该使用清洗后的数据 `data_cleaned` 作为特征，而非原始 `data`

### 错误5：变量错误（M13 目标变量赋值）
- **错误代码**：`y = data[target_variable]`
- **正确写法**：`y = data_cleaned[target_variable]`
- **原因**：应该使用清洗后的数据 `data_cleaned` 作为目标变量，而非原始 `data`

### 错误6：变量错误（M16/M17 保存文件）
- **错误代码**：`data.to_csv(cleaned_file_path, index=False)`
- **正确写法**：`data_cleaned.to_csv(cleaned_file_path, index=False)`
- **原因**：应该保存清洗后的数据 `data_cleaned`，而非原始 `data`
