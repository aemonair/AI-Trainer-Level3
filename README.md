## 🚀 快速开始

### 创建练习文件
```bash
uv run python3 scripts/create_timestamped_practice.py <章节号>
# 例如：uv run python3 scripts/create_timestamped_practice.py 2.1.1
```

### 查看练习历史
```bash
# 查看某章节的所有练习文件
ls *-materials/*practice*.ipynb
```

### 生成复盘文件
- 练习完成后，系统会自动生成 `*_review.md` 文件
- 只记录错误的练习，正确的不生成Review
