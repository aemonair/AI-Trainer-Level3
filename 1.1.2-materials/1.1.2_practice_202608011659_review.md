### 任务3：数据清洗和异常值处理 ❌

#### 错误1：`fillna` 参数错误
```python
# 错误代码
data['Value'].fillna('bfill', inplace=True)
data['Value'].fillna('ffill', inplace=True)

# 正确写法
data['Value'].fillna(method='bfill', inplace=True)
data['Value'].fillna(method='ffill', inplace=True)
```
**原因**：`fillna` 的第一个参数是 `value`，不是 `method`。应该使用关键字参数 `method=`。

#### 错误2：DataFrame调用语法错误
```python
# 错误代码
cleaned_data = data(data=['is_abnormal'])

# 正确写法
cleaned_data = data.drop(columns=['is_abnormal'])
```
**原因**：`data` 是DataFrame对象，不是函数，不能用 `()` 调用。删除列应该使用 `drop()` 方法。

#### 错误信息
```
TypeError: 'DataFrame' object is not callable
```

## 📝 学习要点

1. **`fillna` 方法**：
   - `method='ffill'`：前向填充（用前一个有效值填充）
   - `method='bfill'`：后向填充（用后一个有效值填充）
   - 注意：新版本pandas中 `method` 参数已被弃用，推荐使用 `ffill()` 和 `bfill()` 方法

2. **DataFrame删除列**：
   - 使用 `drop(columns=['列名'])` 删除指定列
   - 使用 `drop(columns=['列名'], inplace=True)` 直接修改原DataFrame
