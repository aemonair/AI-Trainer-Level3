## 🔧 Python代码定义

### 3.1.1 / 3.1.2（默认）
```python
def get_period(h):
    if 6 <= h < 12: return '06:00-12:00'
    if 12 <= h < 18: return '12:00-18:00'
    return '18:00-24:00'
```

### 3.1.3（健康手环）⚠️ 包含边界
```python
def get_period(h):
    if 6 <= h <= 8: return '06:00-08:00'   # 包含8点
    if 17 <= h <= 20: return '17:00-20:00'  # 包含20点
    return '其余时段'
```

### 3.1.4（健康监测）
```python
# 不需要分时段，直接按小时筛选
早晨 = df[(df['hour'] >= 6) & (df['hour'] <= 8)]
凌晨 = df[(df['hour'] >= 0) & (df['hour'] <= 5)]
早餐后 = df[(df['hour'] >= 7) & (df['hour'] <= 9)]
午餐后 = df[(df['hour'] >= 12) & (df['hour'] <= 14)]
晚餐后 = df[(df['hour'] >= 18) & (df['hour'] <= 20)]
```

### 3.1.5（智能家居）⚠️ 13点开始
```python
def get_period(h):
    if 6 <= h < 12: return '06:00-12:00'
    if 12 <= h < 18: return '13:00-18:00'  # 注意是13点
    return '19:00-05:00'  # 注意是19点开始
```
