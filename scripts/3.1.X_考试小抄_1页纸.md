## 📝 核心代码（9行）

```python
import pandas as pd

# 1. 读数据
df = pd.read_excel('数据文件.xlsx')

# 2. 提小时
df['hour'] = pd.to_datetime(df['时间列']).dt.hour

# 3. 分时段
def get_period(h):
    if 6 <= h < 12: return '06:00-12:00'
    if 12 <= h < 18: return '13:00-18:00'
    return '19:00-05:00'
df['period'] = df['hour'].apply(get_period)

# 4. 数频率
df['功能列'].value_counts()

# 5. 分组平均
df.groupby('period')[['列1','列2']].mean()

# 6. 单平均
df['响应时间列'].mean()

# 7. 分组响应
df.groupby('功能列')['响应时间列'].mean()

# 8. 数非空
df['列名'].notna().sum()
```
